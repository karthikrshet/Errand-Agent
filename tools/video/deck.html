Enforced in code

Five guarantees, not five hopes

No action without approval

Single-use grant, fingerprinted to provider, slot and price. Ambiguous replies never grant.

No double booking

Write-ahead intent, idempotency key, unique constraints, atomic grant + intent.

Booked only if verified

On a timeout, ask get_booking_status first. Every claim is checked against the ledger.

Injection can't act

A tool-less sub-agent reads reviews. Per-state tool allowlist. Grants only from the user.

Forgetting is real

Scrubbed from memory, history and live requests. The context manifest proves it.
